# Exercise 01 — Git Basics

This fileaccompanies [exercises/01-basics.md](./01-basics.md) in the student-exercises branch.

## What to practice

1. Clone the repo and inspect the default branch.
2. Create and switch to a new branch.
3. Make a small commit and view the commit history.

Notice how each `git commit` creates its own snapshot in the history — that's what makes the demo read cleanly line by line.
