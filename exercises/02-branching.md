# Exercise 02 — Branching

This placeholder covers the core branching workflow you'll demo in the lab.

## What to practice

1. Create a branch from `main` (we're already on `student-exercises`).
2. Commit changes on the branch without touching `main`.
3. Compare the branch history with the base branch using the commit graph.
4. Delete the branch once the exercise is verified.

## Key commands

```git
git branch tinymd
git checkout tinymd
git commit -m \"add exercise file\"
```
